# Contracts Data

## Introduction

I asked Claude to generate prompts for a variety of hypothetical contracts. I emphesized high variety, length and complexity with realistic fake names and details.

I ran each through Claude Sonnet 4.5 and saved the result in `public/data/contracts/raw`.

I manually converted each to a PDF using [MarkdownToPDF](https://www.markdowntopdf.com) and saved them to `public/data/contracts/pdf`.

So far I've only generated PDFs from the first 3 prompts.
